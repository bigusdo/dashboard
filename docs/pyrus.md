## Как это работает в дашборде (реализовано)
- `server/pyrus.mjs` — читает открытые задачи всех списков (кроме «ОП»), определяет номер КП по заголовку (`КП1091`), статус/объект/тип работ — по спискам. Проверка отдельно: `node server/pyrus.mjs`.
- `server/server.mjs` — обновляет задачи каждые 3 минуты (`PYRUS_REFRESH_MIN`), отдаёт `/api/tasks`. Не зависит от медленной загрузки 1С. «Мне» — задачи, где ответственный `PYRUS_ME` (по умолчанию id 364657, Битус Д.).
- `public/index.html` — карточка «Задачи Pyrus»: вкладки Все / Мне / Просрочено (в т.ч. без срока) / Зависли (без движения ? 3 дней, не мои); клик по заголовку открывает задачу в Pyrus; номер КП открывает карточку КП из 1С; в карточке КП есть список её задач. Задачи без номера КП помечены «нет номера КП».
- Пока только чтение. Ответ на задачу и вложения из дашборда — следующий шаг (проверять на тестовой задаче).

## Ответ на задачу и вложения (реализовано)
- В списке задач у каждой строки кнопка «Ответить»: поле текста и выбор файлов (до ~20 МБ суммарно). Уходит в Pyrus комментарием от имени бота MainBot с префиксом «[из дашборда]».
- `POST /api/tasks/{id}/comment` (JSON `{text, files:[{name, data(base64)}]}`) > `postComment` в `server/pyrus.mjs`: файл грузится `files/upload`, затем комментарий с `attachments`.
- Защита: запрос принимается только со страницы самого дашборда (проверка `Origin`), только для открытых задач из кэша, сервер слушает 127.0.0.1.

- Над списком задач — воронка по спискам-статусам: чипы «Делаем КП > На согласовании > Согласовано > В работе > Ждем денег > Оплачено > Выполнено» (+ «Без статуса») со счётчиком задач и суммой заказов КП из 1С (только для КП, которые 1С считает «в работе»). Клик по чипу фильтрует список.
- Выпадающие списки «Объект» и «Тип работ» (списки Pyrus), кнопка «Сбросить фильтры». Фильтры действуют на все вкладки и их счётчики.
